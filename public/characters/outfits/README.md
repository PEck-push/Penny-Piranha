# Charakter-Outfits / Unterkörper (Builder-Modus, z-10)

Transparente **WebP**, Vorlage **1080×1080**, vollflächig/deckungsgleich (Unterkörper
inkl. Beine an der richtigen Stelle, Rest transparent). Dateiname frei wählbar,
z. B. `outfit_01.webp`.

Nur nötig im **Builder-Modus**. Aktivierung in `src/data/characterParts.ts`:
1. WebP-Dateien hier ablegen.
2. Dateinamen (ohne `.webp`) in `OUTFITS` eintragen.
3. `CHARACTER_MODE = 'builder'` setzen.

Tipp: Verschiedene Trikots = einfach verschiedene Outfit-WebPs.
