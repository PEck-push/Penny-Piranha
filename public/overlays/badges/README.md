# Badge-Overlays (Hintergrund-Ebene, z-0)

Transparente **PNG**, Vorlage **1080×1080**, vollflächig — liegt als Hintergrund
hinter dem Charakter (z. B. Flammen-Aura). Dateiname = `<id>.png`.

**Aktuell automatisch vergeben:**
| Datei | Auslöser |
|---|---|
| `on_fire.png`  | 4er-Streak |
| `damn_hot.png` | 7er-Streak |

nur nötig, wenn wir sie später aktiv setzen):
`whale.png`, `bankrupt.png`, `phoenix.png`, `underdog.png`, `phasekoenig.png`,
`tageskoenig.png`, `arschkarte.png`, `wunderteam.png`
