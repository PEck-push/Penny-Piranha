# Badge-Overlays (Hintergrund-Ebene, z-0)

Transparente **WebP**, Vorlage **1080×1080**, vollflächig — liegt als Hintergrund
hinter dem Charakter (z. B. Flammen-Aura). Dateiname = `<id>.webp`.
