# Accessoire-Overlays

Transparente **PNG**, Vorlage **1080×1080**, vollflächig/deckungsgleich zum Charakter
(das Teil an der richtigen Stelle platzieren, Rest transparent). Dateiname = `<id>.png`.

| Datei | Slot | Auslöser |
|---|---|---|
| `underdog_medal.png` | Hand | Underdog-Sieg (automatisch) |
| `flames.png` | Kopf | 4er-Streak (automatisch) |
| `crown_gold.png` | Kopf | Spieltagskönig (Admin/manuell) |
| `alpenmuetze.png` | Kopf | Österreich-Block-Sieger |
| `jersey_at_gold.png` | Trikot | Österreich-Block-Sieger |
| `jersey_finale.png` | Trikot | Finale-Block-Sieger |
| `trophy.png` | Hand | Turniersieger (Admin/manuell) |

Die IDs stammen aus `src/data/accessories.ts` — neue Accessoires dort ergänzen.
